# Scripts

Helper scripts for the Enterprise Azure Platform repository.

| Script | Description |
|---------|-------------|
| init.sh | Prepare the Terraform project (checks prerequisites, initializes, validates) |
| fmt.sh | Format Terraform code recursively |
| validate.sh | Format and validate Terraform configuration |
| git-status.sh | Show repository status, recent commits, and remotes |
| clean.sh | Remove local Terraform working artifacts |
