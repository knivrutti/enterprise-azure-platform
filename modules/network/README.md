# Network Module

## Purpose

Creates Azure networking resources.

## Planned Resources

- Virtual Network
- Subnets
- Network Security Groups
- Route Tables

## Inputs

| Name | Type | Description |
|------|------|-------------|
| location | string | Azure region |
| resource_group_name | string | Resource Group |

## Outputs

| Name | Description |
|------|-------------|
| vnet_id | Virtual Network ID |
